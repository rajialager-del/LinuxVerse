# Introduction to Linux 🐧

## 1. What is Linux?
Linux is a free and open-source operating system kernel. Linux-based operating systems are widely used in servers, cloud computing, cybersecurity, and DevOps.

## 2. Linux vs Unix
Linux is open source and is available in many distributions. Unix refers to a family of operating systems that includes many commercial and certified variants.

## 3. Popular Linux Distributions
- Ubuntu
- Debian
- Fedora
- Linux Mint
- Red Hat Enterprise Linux (RHEL)

## 4. Why Do We Need Linux?
- To manage servers
- To run cloud applications
- To automate tasks
- To learn DevOps tools
- To build and deploy software

## 5. Linux vs Windows
| Feature | Linux | Windows |
|---|---|---|
| Source | Mostly open source | Proprietary |
| Customization | Highly customizable | More limited |
| Common uses | Servers, cloud, development | Desktop, gaming, business |
| Command line | Shells such as Bash | PowerShell and Command Prompt |

## 6. What Is the Linux Kernel?
The kernel is the core part of an operating system. It manages hardware, memory, processes, and devices.

## 7. Does Linux Have Viruses?
Yes. Linux can be affected by malware. Updates, strong passwords, trusted software sources, and proper permissions help improve security.

## 8. Beginner Linux Commands
- `pwd` — show the current directory
- `ls` — list files and folders
- `cd` — change directory
- `mkdir` — create a directory
- `whoami` — show the current username

## 9. Linux and DevOps
Linux skills help with servers, cloud computing, containers, automation, and deployment.
